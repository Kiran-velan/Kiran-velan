## 🚀 Featured Projects

### 1. [ConsensusWorks](https://github.com/Kiran-velan/ConsensusWorks-Collective_Decision_Making_Platform)
**Java | Spring Boot | Python | FastAPI | Redis | MySQL | WebSockets**

A real-time collective decision-making platform powered by game-theory-based consensus optimization.

- Implemented the Bradley-Terry model for preference evaluation.
- Built adaptive multi-round questioning and real-time collaborative interactions.
- Designed modular backend services and integrated Redis caching.

### 2. [SmartScribe](https://github.com/Kiran-velan/SmartScribe)
**Python | FastAPI | React | Whisper | Hugging Face | Ollama**

An AI-powered media understanding platform for transcription and context-aware question answering.

- Integrated speech-to-text processing using OpenAI Whisper.
- Implemented Retrieval-Augmented Generation for contextual Q&A.
- Integrated local LLMs using Ollama.

### 3. [FinWise](https://github.com/Kiran-velan/Finwise)
**Python | FastAPI | n8n | Yahoo Finance | Groq AI**

An AI-powered personal finance and stock analysis platform.

- Integrated financial market data and news aggregation.
- Implemented RSI, MACD, and SMA-based technical analysis.
- Built automated financial advisory workflows.

### 4. [CLI Coding Support Agent](https://github.com/Kiran-velan/my-cli-coding-support-agent)
**Python | LiteLLM | Gemini | Function Calling**

An AI-powered command-line coding assistant capable of interacting with local development environments.

- Implemented an iterative LLM tool-calling execution loop.
- Built filesystem tools for reading, creating, and modifying source files.
- Integrated shell command execution with explicit user approval.
- Implemented conversation history and multi-step tool orchestration.

### 5. [API Rate Limiting Gateway](https://github.com/Kiran-velan/API-Rate-Limiter)
**Java | Spring Boot | Redis | MySQL**

A configurable API gateway implementing request throttling and subscription-based API access management.

- Implemented Fixed Window and Token Bucket rate-limiting algorithms.
- Integrated Redis-backed request tracking.
- Built tier-based access control and an admin analytics dashboard.
